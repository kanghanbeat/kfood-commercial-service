## ⚠️ 착수 전 결정 필요: 지역 데이터와 시·도의 관계

현재 DB의 지역(regions) 23개는 **동네·도시 단위**(예: Sindang)이고, 지도는 **시·도 17개** 단위다. 지도 클릭과 지역 페이지를 연결하려면 다음 중 하나가 필요:

- **A안 (스키마 무변경)**: 코드에 시·도→지역 매핑표를 상수로 두고, 지도 클릭 시 해당 시·도의 지역 목록 페이지(`/regions?province=seoul`)로 이동
- **B안 (스키마 변경)**: regions 테이블에 `province` 필드 추가 — **한빛 승인 필요(high-risk)**, 대신 구조가 깔끔

→ 1주차 시작 전에 한빛과 함께 선택. 회의 안건 2를 논의할 때 같이 정하면 좋음.

## 주차별 계획 (주당 3개 이하 원칙)

### 1주차 — 뼈대
1. 내비게이션 3카테고리 전환 (음식 / 커뮤니티 / 마이페이지) + 게시판별 어드민 공개/비공개 토글 점검·확대 (카테고리 토글 → 전체 게시판)
2. 음식×지역 URL 라우트 추가: `/foods/[foodSlug]/[regionSlug]` (기존 URL은 그대로 유지)
3. 메인 페이지 4섹션 뼈대 교체 (내용은 기존 컴포넌트 재배치 수준)

### 2주차 — 지도 ✅ 완료 (2026-07-10)
1. ✅ SVG 지도 컴포넌트(`web/components/korea-map.tsx`): 시·도 클릭 → `/regions?province=` 이동, 호버 시 시·도명+대표 음식+지역·음식 수 툴팁. path 데이터는 `web/lib/korea-map-paths.ts`(KOSTAT SVG에서 자동 생성, 직접 수정 금지)
2. ✅ 색칠 로직: 음식 수 기준 3단계 퍼플(#D9BFFF/#B57BFF/#8500FF), 콘텐츠 없는 시·도는 회색+클릭 불가("Guide coming soon" 툴팁)
3. ✅ 매핑 **A안 채택**(스키마 무변경): `web/lib/provinces.ts` 코드 매핑표. ⚠️ 새 지역을 DB에 추가하면 이 파일에도 slug를 등록해야 지도와 연결됨

### 3주차 — 큐레이션 연결
1. 히어로 계절 테마 1호 제작 (예: Summer Naengmyeon Guide — 콘텐츠+배너)
2. 지역 페이지에 "Save this list to your Google Maps" 버튼 (솔이 만든 구글맵 저장 리스트 링크 연결)
3. 음식 페이지 맛집 섹션을 지역별 그룹핑으로 변경 + 전체 목록 조회 잔여분 정리
