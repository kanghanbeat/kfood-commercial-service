## 공개 페이지 · SEO (어드민 업그레이드 끝난 뒤 진행)

> 배경: 수익 경로가 `SNS → 홈페이지 유입 → 애드센스`라, **검색 노출(SEO)** 이 유입의 입구다.
> 아래는 유입을 직접 키우는 작업들. 어드민(콘텐츠 입력 도구)이 안정된 뒤 착수.

- **SEO 강화** ⭐ 유입 1순위
  - 페이지별 메타데이터(제목·설명) 정교화
  - OG 이미지(카카오톡·구글·SNS 공유 시 뜨는 미리보기 썸네일) 자동 생성
  - 구조화 데이터(JSON-LD — 구글이 음식·장소를 표로 인식하게 하는 숨은 표식) 추가
  - 사이트맵(sitemap — 검색엔진에 페이지 목록을 알려주는 파일) 완성도 점검
- **공개 페이지 읽힘 개선** — 음식·지역 상세를 외국인이 더 잘 읽게 레이아웃·정보 배치 정리 (사진 갤러리 들어온 김에)
- **방문자 검색·탐색 개선** — 공개 음식/지역 목록의 검색·필터·정렬(예: 많이 매운·초보자용·지역별)

## 데이터 확장 대비 (지금은 보류 — 조건 충족 시 진행)

> 현재 구조는 유지한다. 한 종류의 항목이 약 500건이면 성능 측정, 1,000건에 가까워지면 아래 1단계를 우선 처리한다.
> 결정 배경과 단계별 상세 내용은 `docs/06-team/work-history.md`의 "향후 개발 계획 — 데이터 증가 대비 확장성 정비" 참고.

- **1단계 — 데이터 증가:** DB 페이지 나누기·DB 검색·공개 목록 조회 제한·사진 삭제 정합성·마이그레이션 `013~015` 운영 적용 확인
- **2단계 — 운영 인원 증가:** 동시 수정 충돌 방지·일괄 변경 트랜잭션·사진 순서 변경 원자화·주인 없는 사진 정리·달력 날짜 범위 조회
- **3단계 — 공개 페이지 증가:** 사이트맵 분할·검색 인덱스·캐시와 성능 관측·데이터 모듈 분리
- **지금 하지 않음:** 전면 재작성·마이크로서비스·외부 검색엔진
