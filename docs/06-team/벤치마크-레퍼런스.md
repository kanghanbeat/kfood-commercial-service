# 벤치마크·레퍼런스 조사 (2026-07-08)

> `기획정렬-한빛대조.md` §1-2 포지셔닝의 근거 자료. 웹 검색 + 사이트 직접 방문으로 검증.

## 종합 판단

1. **우리 모델을 그대로 하는 한국 대상 서비스는 없다.** 조각(음식×지역 DB, 지도 내비게이션, 영어 K푸드 콘텐츠, 구글맵 공유, 예약 전환)은 각각 존재하지만 조합이 없음
2. **일본에는 완성형(byFood)이 있다** — JTB 투자 유치. "방문 외국인 × 음식 콘텐츠 → 전환" 시장 자체가 검증됨. 한국은 영어 식당 발견 공백이 실존 (망고플레이트 종료)
3. **수익 사다리가 단계별로 전부 검증됨**: 애드센스(TasteAtlas) → 제휴(Will Fly For Food) → 협찬·투어(ZenKimchi, Culinary Backstreets) → 예약 수수료(byFood). 우리 계획 순서와 일치

**벤치마킹 우선순위**: 사이트 구조 = byFood 블로그 + TasteAtlas · 지도 UX = TABERUKOTO · 운영·수익 현실성 = Will Fly For Food

## 1. 국가 특화 푸드 트래블 플랫폼 (가장 가까운 모델)

| 서비스 | 무엇 | 수익 | 시사점 |
|---|---|---|---|
| **byFood** (byfood.com, 일본) | 방일 외국인 원스톱 푸드 플랫폼 — 체험·식당 예약 + 47개 현별 향토음식 에디토리얼 | 예약 수수료. JTB·VELTRA 투자 ~$2.2M | 콘텐츠 SEO → 전환 구조의 완성형. 우리의 최종 단계 |
| Savor Japan / Gurunavi EN (일본) | 외국인용 영어 식당 검색·예약 | 식당 광고·예약 수수료 (B2B) | "영어 메뉴 있음" 같은 외국인 실용 정보 필드 차용 |
| Creatrip (creatrip.com, 한국) | 방한 외국인 슈퍼앱 — 예약·쇼핑·환전. MAU 160만+, 투자 $15.1M | 커미션 | 본질은 커머스 OTA. 음식×지역 에디토리얼 없음. 추후 제휴 파트너 후보 |
| Trazy (한국) | 외국인 대상 액티비티·투어 예약 | 커미션 | 동일 — 푸드투어 제휴 링크 대상 |
| **ZenKimchi** (zenkimchi.com, 한국) | 2004년~ 영어 한식 블로그 + 서울 푸드투어 | 투어 예약(주력) + 제휴 | 영어 K푸드 콘텐츠→투어 수익화가 한국에서 20년 작동함을 증명. 단 SEO 아카이브·지도 내비게이션 없음 = 우리의 빈틈 |
| Best of Korea (미국) | 한국 문화 영어 웹매거진 | 광고·스폰서드 | 여행 실행과 연결 안 됨. 톤 참고용 |
| VisitKorea (공공) | "K-Local Food Trip 33" 등 지역 향토음식 콘텐츠 | 없음 | 백과사전식·비큐레이션·전환 없음. 공공이 못 하는 것(주관 큐레이션·루트·지도 저장)이 우리 자리 |

## 2. 음식×지역 콘텐츠 구조

| 서비스 | 무엇 | 수익 | 시사점 |
|---|---|---|---|
| **TasteAtlas** (tasteatlas.com) | 세계 향토음식 지도, 음식 19,000+종 | 광고+라이선스, 연매출 ~$5M 보도. 월 방문 ~128만, 오가닉 79% | 음식×지역 DB의 SEO 파워 증명. 한국 페이지 얕고 실행 정보 없음 → "TasteAtlas 구조 + 여행 실행"이 우리 차별점 |
| Gastro Obscura (atlasobscura.com/gastro) | '신기한 음식' 에디토리얼 | 광고→책→강좌→미식여행 | 궁금증 중심 스토리텔링 톤이 우리 콘텐츠 기준과 일치 |
| Culinary Backstreets | 블로그 1개→17개 도시 푸드투어 회사 | 투어(주력)+가이드북 | 블로그→투어 회사 전환의 대표 사례 |
| Eater | 도시별 "Essential 38" 에디터 선정 리스트+지도 | 미디어 광고·제휴 | "전문가가 고른 유한한 리스트" 포맷의 원조 — 큐레이션 리스트 페이지 포맷 레퍼런스 |

## 3. 기능 레퍼런스

**클릭형 국가 지도 내비게이션**
- **TABERUKOTO** (taberukoto.jp/en/local/): 일본 8지방→47현 클릭 지도로 향토음식·식당 탐색. 외국인 타겟. **일본에선 검증된 포맷, 한국 대상 영어로는 부재**
- Japan House London 인터랙티브 일본 지도, JNTO 지역 특산 요리 페이지

**구글맵 리스트 공유·수익화**
- **Will Fly For Food** (willflyforfood.net/seoul-food-guide/): 가이드마다 전체 식당 핀 공유 구글맵 링크 제공 + Klook/GetYourGuide/Booking 제휴 — 블로거 표준 관행이라 사용자 학습 비용 0
- Wanderlog: 구글맵 연동 플래너 (구독+제휴)
- Thatch (thatch.co) / Rexby: 크리에이터 큐레이션 지도·가이드 **유료 판매** 마켓플레이스 — 추후 프리미엄 지도 판매 확장 경로

## 4. SNS→웹 퍼널

- **Mark Wiens / Migrationology**: 유튜브 1,100만 구독. 영상=발견, 웹사이트=검색·수익 아카이브(광고+이북+투어). 우리 퍼널과 동일 구조
- **Will Fly For Food**: 부부 2인 비개발자 팀이 도시×음식 SEO 가이드 + 지도 공유 + 제휴만으로 지속 운영 — **가장 현실적인 롤모델**
